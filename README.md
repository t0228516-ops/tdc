# Telegram Direct Call (v17, қысқартылған)

Telegram-да нөмірді басқанда жүйелік диалер нөмірді өзі теріп ашады. Бұл қолданба тек диалердегі
«Қоңырау» түймесін басады. Қосымша рұқсат (CALL_PHONE т.б.) керек емес.

## Жинау
GitHub-қа жүктеп, Actions → "Build APK" → Run workflow → Artifacts-тан APK.

## Орнату
1. Қолданбаны ашып, «Қолжетімділік параметрлерін ашу» → «Telegram Direct Call» қосыңыз.
2. Android 13+: Параметрлер → Қолданбалар → Telegram Direct Call → ⋮ → «Шектелген параметрлерге рұқсат беру», сосын қызметті қосыңыз.

## Жұмыс істемесе
Қолданбаны ашып, «Диагностика» мәтінін көшіріп жіберіңіз.
