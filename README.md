# Telegram Direct Call

Telegram-да нөмірді басқанда шығатын мәзірді (Call/Позвонить/Қоңырау шалу) Accessibility арқылы танып,
мәзірді жауып, бірден ACTION_CALL жасайды.

## Жинау (телефоннан)
1. Жобаны GitHub репозиторийіне жүктеңіз (.github/workflows/build.yml қоса).
2. Actions → "Build APK" → Run workflow.
3. Аяқталған соң Artifacts-тан APK жүктеп орнатыңыз.

## Орнату
- Қолданбаны ашып: Accessibility қызметін қосыңыз, Қоңырау рұқсатын беріңіз.
- Android 13+: Параметрлер → Қолданбалар → Telegram Direct Call → ⋮ → «Шектелген параметрлерге рұқсат беру», содан кейін Accessibility-ні қосыңыз.
- Батареяны оңтайландыруды осы қолданбаға өшіріңіз.

## Жұмыс істемесе
Telegram-да нөмірді басыңыз, содан соң қолданбаны ашып «Диагностика» мәтінін көшіріп жіберіңіз —
мәзір мәтінін көріп, сервисті түзетеміз.
